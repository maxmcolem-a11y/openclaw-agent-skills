# Westfield presentation kickoff questions

Use these at the start of a new presentation project. Ask only the missing ones.

## Required questions

1. What is the deck slug or working title?
2. Is this a brand-new deck, or a revision to an existing live URL?
3. Who is the audience, and what decision should the deck help make?
4. What slide outline do you want, in order?
5. Do you already have approved copy, or should I draft / tighten it?
6. What source assets should I use, and where are they located?
7. Which logos or brand marks belong in the deck, and on which slides?
8. Do you want English only, or bilingual support? If bilingual, which languages?
9. Should any images, spec sheets, or PDFs also be localized?
10. What metadata belongs on the closing slide, if any: confidentiality text, owner, author, last edited date?
11. Do you want each revision published live immediately, or should I batch changes before pushing?

## Common follow-ups

- Which slide is the most important one to get right first?
- Should the tone feel internal review, customer-facing, or executive-summary?
- Are there any words, labels, or phrases you do not want used?
- Do you want lightbox zoom, slideshow arrows, clickable dots, or spec-sheet modals?
- Are there STEP files, CAD previews, or other heavy assets that should load on demand?
- Should the cover be minimal, or should it include a hero image?
- Do you want a closing slide, or should the deck end on the last concept slide?
- Should I keep the current live URL stable?
- Do you want a cache-busted URL for review after publish?

## Default assumptions when Max is moving fast

If Max is in a hurry and does not answer everything, assume:

- live HTML deck in `artifacts/westfield-presentations`
- iterative publish to the same URL
- direct design-review tone
- minimal cover slide
- consistent three-image progression layouts
- centered zoom/lightbox behavior
- only intended files get committed

## Fast kickoff message template

Use something like this:

- What should the deck be called?
- New deck or edit an existing live one?
- What slide order do you want?
- Do you already have final copy?
- Which assets/logos should I use?
- English only or bilingual?
- Push each revision live immediately?
